# F1 Race Intelligence Analysis

This project creates a synthetic Formula 1 race dataset and analyzes race performance using Python, pandas, seaborn, and matplotlib.

## Files
- `create_f1_dataset.py` - generates a sample Formula 1 dataset in CSV format
- `analyze_f1_race.py` - reads the CSV and creates charts for performance analysis
- `f1_race_sample.csv` - sample dataset generated by the script

## Requirements
```bash
pip install pandas matplotlib seaborn numpy
```

## Run the project
```bash
python create_f1_dataset.py
python analyze_f1_race.py
```

## What the analysis includes
- Total points by driver
- Average pit stop time by team
- Race pace vs average speed
- Tyre wear vs overtakes
- Driver podium rate

This is a synthetic sample dataset intended for learning, prototyping, and visualization workflows.
